# git-repo-catalog

GitHub 优质仓库目录。用星数圈定值得关注的仓库，分档整理成清单，并对其中最受关注的一批做逐项目深度分析。

## 内容

**按星数分档/** —— 仓库清单。全部仓库按星数区间分档，每档一份 Markdown 清单，档内按全局排名排列。字段：全局排名、仓库、Stars、语言、最近推送、简介。

**项目分析/** —— 深度分析报告。对高星仓库逐个分析源码，每仓库一篇，文件名 `<owner>__<name>.md`（如 `sindresorhus__awesome.md`），按档位分目录存放。

[`目录树.md`](目录树.md) 是整个仓库的索引：9 份清单的入口，以及全部 1010 篇分析的排名、仓库、星数、语言与文档链接。

```
    ├── 50k-100k/          # 384 篇
    └── 20k-50k/           # 491 篇
```

## 分析报告

每篇报告固定 10 个章节，便于横向对比：

1. 项目速览
2. 项目是什么，解决什么问题
3. 技术栈与依赖
4. 目录结构与代码组织
5. 核心架构与关键实现
6. 构建与运行
7. 测试与工程质量
8. 社区与维护状态
9. 亮点与风险
10. 总结评价

关键结论均注明源码出处。内容型仓库（awesome 清单、学习路线、书籍、题库等）不套代码架构模板，改为分析收录范围、分类体系、条目规模、更新机制与生态位。
