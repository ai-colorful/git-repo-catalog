## 1. 项目速览

一句话定位：把国家免费开放的中小学（及少量大学）电子教材 PDF 系统性搬上 GitHub 的"内容型仓库"，让内地学生绕开网盘/收费水印渠道、海外华人子女照常使用国内教材。

## 2. 项目是什么，解决什么问题

README（`README.md`，9.3KB）开篇"项目的由来"交代了动机：国内教育网站虽已免费提供教材资源，但普通人获取渠道受限，有人趁机在某站售卖带私人水印的扫描件；作者因此把资源集中开源，"促进义务教育的普及和消除地区间的教育贫困"，并明确提到第二个目的——"希望海外华人能够让自己的孩子继续了解国内教育"。

仓库主体是按"学段 → 学科 → 教材版本（出版社）→ 年级 → PDF"组织的教材扫描件。以小学数学人教版为例，路径形如 `小学/数学/人教版/义务教育教科书 · 数学一年级上册.pdf`。内容覆盖小学、初中、高中全部主流学科，另有"五•四学制"（五四制教材，主要供山东等地区）专区和大学数学基础课（同济高数第七版/第六版、同济线性代数第五版、离散数学及其应用、浙大概率论），以及一个"学数学最重要的刷习题在这里"专区收录 2017-2018 年多省市中考数学真题带答案（`学数学最重要的刷习题在这里/初中练习题_带答案/`，含北京、上海、南京、河北、浙江、湖北、重庆、河南等地卷及人教版中考模拟卷）。

它解决的实际痛点有三个：一是渠道问题，官方平台（国家中小学智慧教育平台等）虽有资源但下载门槛高、国内访问慢；二是完整性问题，逐册收集、按出版社版本齐全归类的工作没人做，本仓库做齐了（46 个"学科-版本"组合，详见第 7 章）；三是境外访问问题，README 明确建议"位于国外、和内地网络通信速度较慢的用户使用本存储库进行签出"。

README 同时坦承资源来源与再分发伦理：它不声称拥有版权，推荐内地用户可用开源项目 [tchMaterial-parser](https://github.com/happycola233/tchMaterial-parser) 从官方渠道重新下载，本仓库的价值在于聚合与境外可达性。仓库不接受 PR 上传教材正文，内容基本由作者与主要贡献者维护。

## 3. 技术栈与依赖

这是一个内容型仓库，几乎没有传统意义上的"技术栈"：

- 内容资产：1905 个完整 PDF + 182 套按块拆分的大 PDF（`.pdf.1`~`.pdf.11` 后缀块文件）+ 1 个 djvu（英文版 Discrete Mathematics and Its Applications 6th，`大学/离散数学/`）。
- 配套工具：mergePDFs 合并程序（Go 编写的多平台二进制），2025-05 起迁往姊妹仓库 TapXWorld/ChinaTextbook-tools 以 release 形式分发（v0.0.1，4 个平台资产）。主仓库仍残留一份 1.9MB 的 `mergePDFs.exe`（`高中/英语/重庆大学版-重庆大学出版社/mergePDFs.exe`）。
- 仓库内唯一的"代码资产"就是上述 exe；无任何脚本、CI、构建系统。

一个有趣的观察：清单里主语言标为 "Roff"，这是 GitHub Linguist 的副作用——超过 50MB 被 Git 拒收的 PDF 被拆成 `xxx.pdf.1`、`xxx.pdf.2` 等"数字后缀"文件（共 465 个块文件），Linguist 把 `.1/.2/.3` 识别为 Roff/man page 格式。语言统计与项目实质（PDF 集合）无关。

## 5. 核心架构与关键实现

### 5.1 内容组织与版本覆盖

分类体系的核心是"多版本并举"：同一学科收录全国各省市在用的全部教材版本。数学作为招牌学科（README 专设"学习数学"章节并附各年级直链），覆盖如下（出处：git trees 全量枚举统计）：

| 学段 | 版本数 | 版本列表 |
| --- | --- | --- |
| 小学 | 8 | 人教、北师大、冀教、北京、西南大学、苏教等 |
| 初中 | 10 | 人教、北师大、华东师大、苏科、青岛、浙教、湘教、冀教、北京、沪科技 |
| 高中 | 7 | 人教 A 版、人教 B 版、北师大、湘教、苏教、沪教、鄂教 |

版本目录名内还保留主编信息（如"人教版（A版）（主编：章建跃&李增沪）-人民教育出版社"），便于教师按书号辨认。相对地，语文只有统编版（小学 12 个文件、初中 6、高中 5），覆盖明显偏薄——全国语文教材高度统一，客观上无需多版本；而美术/音乐类因各省版本林立，收录了最多的版本次（初中美术 12 个版本）。

### 5.2 GitHub 100MB 限制的工程化应对

README 专设"如何合并被拆分的文件"章节：GitHub 单文件上限 100MB，仓库把超过 50MB 的 PDF 按 35MB 一块拆分（实际树中存在 35840KB 与 46080KB 两代块大小），用户下载后把 `mergePDFs-windows-amd64.exe` 放进同目录双击即可自动按序拼接还原。这是本仓库唯一的"工程实现"，逻辑极其简单但对目标用户（家长、学生）足够友好：零命令行。树中还可见旧约定目录 `*.pdf_merge_folder/`，如 `初中/体育与健康/华中师大版-华中师范大学出版社/七年级/义务教育教科书·体育与健康七年级全一册.pdf_merge_folder/`，说明拆分方案经历过一次规范化。

### 5.3 姊妹仓库与工具链

`TapXWorld/ChinaTextbook-tools`（创建于 2025-05-18，517 星）承担所有"会杀毒报毒、会超 Git 限制"的部分：merge/split 二进制以 GitHub Release 分发。2025-05-18 主仓库提交信息 "solving suspected virus problems" 与该仓库创建同日——exe 被杀毒软件误报后，作者把工具迁出主仓库以保住内容仓库的干净性。生态上游则是 tchMaterial-parser（从智慧教育平台抓取原版 PDF 的第三方解析器），README 明确致谢并引流，形成"官方平台 → parser/本仓库 → 用户"的分发链。

## 6. 构建与运行

无构建、无测试、无 CI（仓库无 `.github/` 目录）。用户侧实际可用的操作（来自 README）：

1. 整库获取：`git clone --depth 1 https://github.com/TapXWorld/ChinaTextbook.git`（43.4GB，README 建议境外用户或网络良好者使用；社区 issue #270 专门讨论 clone 超时的替代方案）。
2. 网页浏览：README 自带"学习数学"人肉索引，逐册直链小学数学人教版 12 册、初中数学 6 册及高中数学、大学四门课的目录页——README 本身充当了首页导航。
3. 大文件还原：从 ChinaTextbook-tools release 下载对应平台 mergePDFs 二进制，放入含 `.pdf.N` 块的目录执行，自动合并。
4. 内地重新下载：使用 tchMaterial-parser 按书页 URL 从官方渠道直接获取原始 PDF。

## 7. 收录规模与分类体系

基于 git trees API 全量数据（3112 个条目，未截断）的精确统计：

- 文件构成：2375 个 blob，总计 43.42 GB。其中完整 PDF 1905 个、拆分块 465 个（对应约 182 套大书）、djvu 1 个、exe 1 个、png 1 个、md 1 个。
- 拆分块的分布为 `.1`×182、`.2`×182、`.3`×61、`.4`×22，最深的《体育与健康教师用书（未来社版）水平三》拆到 `.11`——即单本超 350MB 的教师用书（`小学/体育与健康/未来社版/`）。
- 学段-学段差异大：小学 1053 个文件（19.4GB）多于初高中，因小学英语/音乐/美术各省版本与年级组合极多；大学部仅 19 个文件，明显是附带内容。
- 单文件最大 96.3MB（`初中/物理/北师大版（主编：闫金铎）-北京师范大学出版社/九年级/义务教育教科书·物理九年级全一册.pdf`），恰好压在 GitHub 100MB 红线下。
- 学科覆盖：小学 10 科（英语/音乐/科学/美术/数学/体育/书法/语文/道德与法治/艺术），初中 18 科（另含俄语、日语、人文地理、地理图册），高中 18 科（另含信息技术、通用技术、思想政治）。
- 版本覆盖：46 个"学科-版本"组合；数学类覆盖最深（初中 10 版），艺术类出版版本次多（初中美术 12 版）。
- 抽样验证：随机下载 `学数学最重要的刷习题在这里/初中练习题_带答案/初中数学年人教版中考模拟试卷/初中数学年人教版中考模拟试卷-答案.pdf`（90KB），确认为合法 `%PDF-1.4` 文件且字节数与 git 树记录一致（90097B）。

## 9. 亮点与风险

亮点：

1. 教材版本的完整度在中文开源界几乎独一份：46 个学科-版本组合、学段全覆盖，且目录命名规范到"版本-出版社-年级"，可被程序化检索。
2. 对 GitHub 平台限制的应对成熟：50MB+ 自动拆分 + 免命令行合并工具 + 姊妹仓库隔离杀毒误报，内容仓库保持纯净。
3. 精准切中真实需求：境外华人子女教材获取、内地反"水印收费"需求，README 动机陈述坦诚且有共情力。
4. 与 tchMaterial-parser 等上游工具互补引流，形成小生态而非孤立资源堆。

风险/局限：

1. 版权合规是根本性风险：教材著作权属各出版社（人教社、北师大社等），仓库无 LICENSE、未获授权即再分发完整扫描件，README 亦未提供授权说明；2026-09 的平台临时封禁（issue #260）与 fork 同步被禁的机制表明 DMCA/平台政策风险随时可能重演，整库随时可能消失——这也是 fork 数极高的原因之一。
2. 分发成本极高：43.4GB 体积导致 clone 超时成为社区头号痛点（issue #264、#270），仓库没有提供 rsync/网盘/分卷压缩等替代通道，全靠 git 一条路。
3. 维护单点化：3 个贡献者、教材正文基本不再更新，2026 年新教材（如 issue #265 求的版本）依赖零星补传；若核心维护者停更，资源将快速过时。
4. 残留 exe 的信任成本：主仓库仍有一份 `mergePDFs.exe`（`高中/英语/重庆大学版-重庆大学出版社/`），曾被杀软报毒（提交 "solving suspected virus problems"），对不读 README 的新用户存在安全隐患与困惑。

## 10. 总结评价

ChinaTextbook 是"内容即产品"的极端样本：没有任何传统代码架构，却靠一套设计良好的目录分类、对平台限制的工程化拆解和清晰的情感叙事，把"国家免费的教材如何可靠地到达需要的人手里"这件事做到了开源社区的天花板，也因此收获了 8 万+ 星。它的价值与它的风险同源——再分发版权物让它随时可能被下架，43.4GB 的体积让它难以搬运，单人维护让它缺乏后手。对普通用户，它是目前获取国内 K12 教材最完整的开源镜像，用前先读 README 的合并说明；对想读"源码"的人，真正值得研究的是它的内容组织范式（学段/学科/版本/年级四层分类 + 拆分块约定）与"内容仓库 + 工具仓库分离"的生态设计，而非任何一行代码。
